# Reframe

Write down a harsh thought and see a kinder, truer way to look at it. Anonymous: nothing you write is saved.

- `app/`: the website. One Cloudflare Worker serves the page and the `/api/reframe` endpoint. See `app/README.md` to run or deploy it.
- `brain/`: the AI prompt and safety logic shared by the app, plus an eval with test thoughts.

Crisis language always shows Singapore SOS resources instead of a reframe.
